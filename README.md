### 📝 Deskripsi Singkat

Teh Kataji adalah aplikasi penjualan online yang dirancang untuk membantu pedagang UMKM dalam pencatatan transaksi penjualan secara real-time, pencetakan struk, dan manajemen stok barang berbasis cloud Supabase.
